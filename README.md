# MyITStech

## Description
MyITStech is a professional IT consulting and services website showcasing comprehensive technology solutions. This website serves as the digital presence for MyITStech, featuring various IT services including data analytics consulting, hardware services, and Microsoft Power BI solutions.

## Features
- **Responsive Design**: Mobile-friendly and fully responsive layout
- **Service Showcases**: Detailed pages for different IT services
- **Client Testimonials**: Display of satisfied clients and their feedback
- **Contact Form**: Easy-to-use contact form for inquiries
- **Modern UI**: Clean and professional user interface

## Services Offered
- **Data Analytics Consulting Services**
- **Hardware Services**
- **Microsoft Power BI Services**
- **General IT Consulting**

## Project Structure

### Main Pages
- `index.html` - Homepage
- `service.html` - Services overview
- `about.html` - Company information
- `contact.html` - Contact page
- `solutions.html` - Solutions and offerings
- `consulting-service-detail.html` - Detailed consulting information
- `privacy-policy.html` - Privacy policy
- `terms&condition.html` - Terms and conditions

### Assets
- **CSS**: Stylesheets including main `style.css`
- **JavaScript**: Core scripts in `main.js`
- **Images**: Client logos and testimonial images
- **Vendors**: 
  - AOS (Animate On Scroll)
  - Bootstrap (CSS Framework)
  - Bootstrap Icons
  - GLightbox (Image gallery)
  - Swiper (Carousel)
  - Purecounter (Number counter animation)
  - PHP Email Form (Email validation)

## Technologies Used
- **HTML5** - Structure
- **CSS3 & SCSS** - Styling
- **Bootstrap** - Responsive grid framework
- **JavaScript** - Interactivity
- **AOS** - Scroll animations
- **Swiper** - Mobile touch carousel
- **GLightbox** - Lightbox gallery

## How to Use

1. **Clone or Download** the project files
2. **Open** `index.html` in your web browser
3. **Navigate** through different pages using the navigation menu
4. **Contact** via the contact form for inquiries

## File Organization
- Root directory contains all HTML pages
- `assets/` directory contains all resources:
  - `css/` - Stylesheets
  - `js/` - JavaScript files
  - `img/` - Images (clients, testimonials)
  - `scss/` - SCSS source files
  - `vendor/` - Third-party libraries

## Contact
For inquiries or additional information, use the contact form on the website or refer to the `contact.html` page.
